# Game notes

One file per game that needs more than the default launch of its launcher. The file name is the recipe id. `brink.md` belongs to `Recipes/brink.json`.

Each tweak has three parts:

- **Symptom.** What you see when the game fails.
- **Change.** What this recipe does.
- **Reuse.** When to try the same change on another game.

Read these files before a new investigation. Release notes do not include them. Release notes only name the supported game.
