# Age of Empires III (2007)

Recipe: [aoe3-2007.json](../aoe3-2007.json)

## Missing DLL

**Symptom.** A dialog says that `mfc42.dll` is missing. The CD-key check needs it.

**Change.** Play unpacks `mfc42.dll` beside `bin/age3.exe`.

**Reuse.** Find the import the missing DLL needs. If Wine does not have it, bundle the DLL and copy it in `GameFixes`.
